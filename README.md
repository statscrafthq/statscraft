# StatsCraft

A statistics workbench written in Rust: a command-line engine first, a desktop application after.

StatsCraft is an independent project. It is not affiliated with any software vendor, the GNU PSPP project or the ArtCraft suite.

Status: early development. Licensed under MIT.

## What works today

```
statscraft describe survey.sav           one line per variable
statscraft describe survey.sav --json    full dictionary and counts as JSON
```

`describe` reads `.sav` and `.zsav` files and reports variables, labels, value labels, missing-value definitions, measure levels, multiple response sets, the weight variable, and per-variable counts of valid, system-missing and user-missing cases.

## Development

```
cargo test
```

Test data lives in `tests/fixtures/`. It is synthetic and generated by the scripts in that folder.
