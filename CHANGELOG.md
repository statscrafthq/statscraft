# Changelog

## Unreleased

- MANOVA /ANALYSIS takes several groups of analyses in parentheses ((a b / c) WITH covariates), CONDITIONAL and UNCONDITIONAL, and works with WSFACTORS: each group is an analysis of its own, its dependents the within-subjects cells.

## 0.31.0 (2026-11-23)

- PROXSCAL /PLOT=CORRELATIONS VARIABLES(list | ALL): the Correlations plot of the independent variables with the dimensions (on by default with RESTRICTIONS=VARIABLES) and a Transformation Plot of each variable named.
- PROXSCAL /INITIAL=('file' | dataset) [varlist]: start from the coordinates of a file, one case per object.
- SURVIVAL /WRITE=TABLES and BOTH write the life tables to the PROCEDURE OUTPUT file in the fixed-column record layout of the manual (types 10, 20, 30, 31 and 40).
- PROXSCAL /RESTRICTIONS=VARIABLES('file' | dataset) [ALL | FIRST(n) | varlist] [(kinds)]: the common space is a weighted sum of independent variables, each INTERVAL, NOMINAL, ORDINAL(KEEPTIES | UNTIE) or SPLINE; PRINT VARIABLES and CORRELATIONS show the transformed variables, their regression weights and their correlations with the dimensions, and OUTFILE VARIABLES writes the transformed variables. Identity model only.
- GLM PLOT=PROFILE with WSFACTOR: profile plots of the estimated marginal means over between-subjects and within-subjects factors (error bars and the grand mean line as without WSFACTOR; a chart per measure with MEASURE).
- PROXSCAL /RESTRICTIONS=COORDINATES('file' | dataset) [ALL | varlist]: fixes coordinates of the common space (a missing value frees that coordinate); the fixed ones come out exactly as given and the free ones minimize the stress with them held. Identity model only.

## 0.30.0 (2026-11-23)

- TREE /PLOT MEAN for a scale dependent: the mean of the first p percent of the cases at each percentile group.
- TREE /PROFITS CUSTOM=category [revenue expense] ...: profit summary tables (average profit, ROI and index by node, cumulatively and by percentile) for a categorical dependent, and /PLOT PROFIT and ROI.
- GENLINMIXED accepts a model with neither RANDOM nor REPEATED_MEASURES: a generalized linear model of the fixed effects (it was an error that sent users to GENLIN).
- TREE /RULES NODES=TOPN(n), TOPPCT(p) and MININDEX(v) write rules for the terminal nodes with the largest index values of the first target category, and OUTFILE='file' writes the rules to a text file.
- TREE /RULES NODES=TERMINAL | ALL SYNTAX=INTERNAL | SQL | GENERIC TYPE=SCORING | SELECTION SURROGATES LABELS: the tree as rules, in a Rules table: DO IF blocks of the command language (run in the tests and agreeing with SAVE), SQL, or sentences with labels; surrogates and the larger side route cases with missing values as the tree does.
- TREE gain summaries for a scale dependent: the node table gains cumulative size, mean and index (CUMULATIVE=NO leaves them out), GAIN TYPE=[PTILE] INCREMENT=n adds the percentile table, SUMMARYTABLE=NO turns the summaries off, and CATEGORYTABLE no longer does.
- GENLIN with REPEATED takes ANALYSISTYPE=1(LR) and 3(LR): the generalized score chi-square of each effect (the estimating equations solved under the effect's L matrix) in the Tests of Model Effects.
- TREE /GAIN TYPE=[NODE, PTILE] INCREMENT=n: percentile gain tables for each target category (and sample), with the cases in each percentile, the gain count and share, response, index and the nodes in it.
- TREE gain tables and charts with priors that are not the data's (CRT or QUEST with PRIORS EQUAL or CUSTOM, or ADJUST) now count the nodes by their probabilities under those priors, as the manual's second case says: size share, response and index (and the cumulative figures and percentile charts) change; with priors from the data and for CHAID nothing moves.
- ADP /TRANSFORM CONSTRUCTION=YES(ROOT=name) builds new predictors from groups of correlated continuous inputs (their first principal component) for a continuous target, with the selection of the other inputs by partial correlation, written into the preparation syntax.
- TREE CHAID and exhaustive CHAID accept a scale dependent: categories merge and nodes split by the ANOVA F test of the dependent's means, with the same node tables, risk, gain summary, SAVE and validation as CRT. A numeric dependent without a level is scale, so the default method no longer stops with a request for a level.
- TREE /PRIORS ADJUST=YES: the priors of a CRT or QUEST tree are altered by the misclassification costs (each prior times the sum of its category's costs), which then count as equal for growing, assignment and risk.
- TREE /COSTS CUSTOM=actual predicted [cost] ...: nodes are assigned the category of least expected cost, the risk and its error are the mean cost of the assignments (also in split-sample and cross-validation), CRT with the Gini measure counts the costs in its impurity, and pruning uses them.
- GLM EMMEANS COMPARE gives the test of the compared factor: Multivariate Tests in the multivariate model (the four statistics over all dependents), and with WSFACTOR a Univariate Tests table for a between-subjects factor and a Multivariate Tests table for a within-subjects one.
- TREE validation (split sample and cross-validation) also works for a scale dependent under CRT: the risk is the mean squared deviation from the training node means, with its standard error.
- GLM with WSFACTOR takes SAVE: the predicted values, residuals and the other keywords of each dependent variable.
- GLM with WSFACTOR takes CONTRAST, LMATRIX, KMATRIX, MMATRIX, TEST(MMATRIX) and POSTHOC: the hypotheses and multiple comparisons of the between-subjects factors on the average of the cells (or on the transformation MMATRIX gives).
- TREE /VALIDATION TYPE=CROSSVALIDATION(folds): the Risk table gives the cross-validated estimate (the pooled misses of the fold trees) next to the resubstitution one.
- GLM with WSFACTOR takes EMMEANS: estimated marginal means of between-subjects and within-subjects factors and their crossings, with pairwise comparisons (COMPARE, ADJ) that use the covariance of the dependent variables.
- TREE /VALIDATION TYPE=SPLITSAMPLE(percent or variable) with OUTPUT=BOTHSAMPLES or TESTSAMPLE for every method: the tree grows on the training cases, the Risk, Classification and gain tables and charts come for both samples, the test sample's risk drives PRUNE, and SAVE covers all cases.
- GLM with WSFACTOR takes PRINT HOMOGENEITY, PARAMETER, LOF, RSSCP, TEST(SSCP), TEST(LMATRIX) and GEF: the tables of the original dependent variables under the between-subjects design (Box's M and Levene's tests, parameter estimates, lack of fit, design and SSCP matrices), as the multivariate model prints them.

## 0.29.0 (2026-11-23)

- TREE /METHOD TYPE=QUEST grows a binary tree for a nominal dependent: each node picks the predictor by an F test (scale, ordinal) or chi-square test (nominal) against the classes, with a Levene test of the spread as the second chance, and cuts at the root of the discriminant equation of two groups of classes; /QUEST ALPHASPLIT, priors, surrogates, pruning and SAVE work as in CRT. A nominal predictor (up to 25 categories) is scored by its largest discriminant coordinate and cut like a scale predictor.
- GLM /MEASURE: a doubly multivariate repeated measures model (several measures over the cells of the within-subjects design): each measure has its own sphericity, within-subjects and between-subjects tests, and the multivariate tests take the transformed variables of all measures together.
- NPAR TESTS /METHOD=EXACT: when the exact significance of the Kruskal-Wallis, Jonckheere-Terpstra, Friedman, Kendall's W, Cochran or marginal homogeneity test needs too many steps, it says so at once (from a lower bound of the steps) instead of after minutes of work; the exact walks that do fit run faster and give the same numbers on every run.
- Post hoc tests on the studentized range, the maximum modulus and Dunnett's distribution (TUKEY, BTUKEY, GH, C, DUNNETT, GT2 and the others, in ONEWAY, UNIANOVA and GLM) run 10 to 40 times faster: the integrals take far fewer points and the critical values about 4 evaluations instead of 20. With fewer than about 5 degrees of freedom (Games-Howell between small groups) the critical values far in the tail were off, at 1 df and alpha 0.001 by as much as 80%, and significances by up to 3e-3; all three distributions are now within about 1e-12 everywhere.

## 0.28.0 (2026-11-22)

- TREE /METHOD TYPE=CRT grows a binary classification tree for a nominal or ordinal dependent: every cut of a scale or ordinal predictor and every subset of a nominal one is tried; /CRT IMPURITY=GINI, TWOING or ORDEREDTWOING, MINIMPROVEMENT, /PRIORS FROMDATA, EQUAL or CUSTOM, and the prior probabilities drive each node's category, the risk and the saved probabilities.
- TREE CRT PRINT IMPORTANCE and PLOT IMPORTANCE: the importance of each predictor (the improvements of its splits as main splitter or surrogate, relative to the largest).
- TREE CRT takes a scale dependent (least squares deviation): node means and standard deviations, the mean squared deviation as risk with its standard error, a gain summary by node, SAVE NODEID and PREDVAL; surrogates, pruning and importance work the same way.
- TREE CRT /METHOD PRUNE=SE(b): cost-complexity pruning, keeping the smallest subtree within b standard errors of the lowest risk (resubstitution).
- TREE CRT surrogate splits (METHOD MAXSURROGATES) route cases with a missing split value; PRINT SURROGATES lists each node's surrogates with their association.
- GENLIN CITYPE=PROFILE also gives the profile likelihood interval of an estimated scale and of an estimated negative binomial k.
- Window: Univariate takes random factors (RANDOM).
- UNIANOVA and GLM /RANDOM: random effects with the Expected Mean Squares table and each effect tested against its own combination of mean squares (Satterthwaite's degrees of freedom).
- FACTOR /MATRIX=IN(FAC=...) reads a factor-loading matrix (such as one MATRIX=OUT(FAC=...) wrote) and gives its communalities, the variance it accounts for, the loadings and the rotation asked for.
- DISCRIMINANT /MATRIX=OUT writes the group counts and means and the pooled deviations and correlations of the first analysis as a matrix data file.
- CLUSTER /MATRIX=OUT writes the proximity matrix of the run (rows of type PROX, the layout PROXIMITIES writes) to a file, a dataset or the active dataset.
- FACTOR /MATRIX=OUT(FAC=...) writes the factor loadings, one record per factor, and OUT(FSC=...) the means, standard deviations and factor score coefficients.
- NPAR TESTS /METHOD=EXACT gives the exact significance of the marginal homogeneity test (two-sided, one-sided and point probability).

## 0.27.0 (2026-11-22)

- GENLIN /CRITERIA INITIAL=numbers: the starting values of the coefficients (all parameters, redundant ones included).
- Window: the legacy nonparametric dialogs (NPAR TESTS) add exact significances.
- Window: Generalized Linear Models takes typed initial values of the parameters.
- NPAR TESTS /METHOD=EXACT gives the exact significance of the two-sample Kolmogorov-Smirnov test (with its point probability), the median test of several groups, the Kruskal-Wallis and the Jonckheere-Terpstra tests.
- NPAR TESTS /METHOD=EXACT gives the exact significance (and point probability) of the Friedman, Kendall's W and Cochran tests.
- FACTOR /MATRIX=OUT(COR=...) and OUT(COV=...) write the means, standard deviations, counts and the correlation or covariance matrix of the run to a file, a dataset or the active dataset; OUT may follow VARIABLES.
- CORRELATIONS /CI (Fisher's interval, BIAS, CILEVEL) and NONPAR CORR /CI (Spearman's rho with the FHP, CC or BW standard error): lower and upper limits under each coefficient.
- FACTOR /METHOD=COVARIANCE with PC, PAF and IMAGE: the analysis of the covariance matrix, with the raw and the rescaled loadings, communalities and sums of squares side by side, MINEIGEN in mean variances, and DET and INV of the covariance matrix.
- Window: Bivariate Correlations adds confidence intervals with their level, the bias adjustment for Pearson and the standard error for Spearman.
- Window: Factor analyzes the correlation or the covariance matrix (principal components, principal axis and image factoring).
- DISCRIMINANT /ROTATE=COEFF and STRUCTURE: a varimax rotation of the functions with its transformation matrix (and the share of the between-groups variance of each rotated function), the rotated standardized coefficients and the rotated structure matrix.
- CORRELATIONS /MATRIX=OUT and NONPAR CORR /MATRIX=OUT write the matrix data file of the last list without WITH (MEAN, STDDEV, N and CORR; N and RHO or TAUB), per split group.
- GENLIN /CRITERIA CITYPE=PROFILE: profile likelihood confidence intervals for the regression parameters (and Exp(B)) instead of Wald ones, for the models other than the ordinal multinomial and REPEATED.
- DISCRIMINANT /PLOT=CASES with /STATISTICS=CROSSVALID adds the cross-validated rows to the Casewise Statistics table: the group, posteriors and squared distances of the rule refitted without each case.
- UNIANOVA and GLM PRINT=MBP, BP, F and WHITE with MBPDESIGN, BPDESIGN and FDESIGN: the Breusch-Pagan, modified Breusch-Pagan, F and White tests for heteroskedasticity.
- Window: Univariate and Multivariate offer the tests for heteroskedasticity, each of the first three on the predicted values or on the terms of the model, and Univariate the parameter estimates with robust standard errors (HC0 to HC4).
- Window: Generalized Linear Models chooses Wald or profile likelihood confidence intervals, with the tolerance of the profile.

## 0.26.0 (2026-11-22)

- UNIANOVA and GLM /ROBUST=HC0 to HC4 (HC3 by default): robust parameter estimates, Wald F tests of the effects and a robust set of CONTRAST and LMATRIX results, for models with one dependent variable.
- CATREG, CATPCA and the other procedures that group a fractional variable with DISTR=NORMAL: the cut points of NCAT groups above about 15 were not fully converged (7e-6 off at 20 groups, 2e-3 at 28, 2e-2 at 36); they are now found to 1e-14.
- PREFSCAL /TRANSFORMATION=SMOOTH[(KEEPTIES | UNTIE)] is read instead of refused: the run is the ORDINAL one, with a warning that the smoothing is not applied.
- Window: Multidimensional Unfolding starts from coordinates in a file and fixes the coordinates of the rows or the columns from a file (Restrictions), each with the variables to read.

## 0.25.0 (2026-11-22)

- BOOTSTRAP /SAMPLING METHOD=RESIDUAL and WILD: resamples that keep the cases and rebuild the target from its predicted values and residuals.
- PREFSCAL /RESTRICTIONS=ROW and COLUMN(COORDINATES (file) [varlist]) fixes the coordinates of the row or column objects (a missing value leaves that coordinate free, a whole set is external unfolding), and /INITIAL=(file) [varlist] starts from given coordinates.
- ONEWAY /MATRIX=IN and OUT: the analysis of variance from a matrix data file of group means, standard deviations and counts (or pooled variance), and the group summaries of the run written.
- RELIABILITY /MATRIX=IN and OUT (NOPRINT): the scale statistics from a matrix data file of counts, means, standard deviations and correlations, and the matrix of the run written.
- TSMODEL and TSAPPLY /MODELSUMMARY PLOT draws the histograms of the fit measures across the models and the boxplots of the residual ACF and PACF by lag, instead of a warning.
- Window: Create Models and Apply Models add the statistics and charts that compare models (goodness of fit, residual autocorrelations, a histogram of each fit measure, boxplots of the residual autocorrelations) and the residual autocorrelation charts of each model; those that need residuals are greyed out when Apply Models does not estimate again.
- PARTIAL CORR MATRIX=IN and OUT: partial correlations from a matrix data file of correlations and counts, and the matrix of the first list written to a file, a dataset or the active dataset.
- REGRESSION MATRIX=IN and OUT: the equation from a matrix data file of means, standard deviations, counts and correlations, and the matrix of the run written to a file, a dataset or the active dataset.
- DMLOGISTIC, DMROC, DMTREE and DMTABLES are other names for LOGISTIC REGRESSION, ROC, TREE and CTABLES, as DMCLUSTER already is for TWOSTEP CLUSTER: the same subcommands, defaults and tables. DMT alone is ambiguous between DMTABLES and DMTREE.

## 0.24.0 (2026-11-21)

- GENLIN /PRINT=GEF gives the general estimable function and /PRINT=LMATRIX the L' matrix of each effect's test and of each estimated marginal mean.
- GENLIN /PRINT=HISTORY[(n)] lists the iterations of the last fit with the log likelihood, then the last gradient and Hessian, for the generalized linear models, the ordinal model and the estimating equations.
- GENLIN /PRINT=LAGRANGE gives the Lagrange multiplier test of a fixed scale (normal, gamma, inverse Gaussian) or of a fixed negative binomial k, and for NEGBIN(0) the dispersion z test.
- NOMREG /TEST=effect values (or ALL values) tests linear combinations of the parameters, with Wald chi-squares for each logit and for all logits together.
- GLM and UNIANOVA /PRINT=GEF (the general form of the estimable functions) and /PRINT=TEST(LMATRIX) (the L' matrix of every effect, and of LMATRIX and CONTRAST) give tables instead of being refused.
- GLM and UNIANOVA /TEST=effect VS error term tests an effect against a linear combination of the mean squares of others (Satterthwaite's df unless DF is given) or a given mean square with DF.
- Window: the options of Univariate and Multivariate add the contrast coefficient matrix and the general estimable function. Generalized Linear Models adds them too under Statistics, with the iteration history (every n-th iteration) and the Lagrange multiplier test.

## 0.22.0 (2026-11-21)

- GLM and UNIANOVA /CONTRAST(factor)=SPECIAL(matrix): the matrix is read column by column, the first column the constant and each other column one contrast, as the manual's example shows.
- REGRESSION /METHOD=TEST(set)(set)... enters the sets together and tests each by the change in R square when it leaves (a Subset Tests table with the change, sum of squares, df, F and significance).

## 0.21.0 (2026-11-21)

- Window: the new choices are in the dialogs. One-Way ANOVA has Contrasts with a polynomial trend (linear up to 5th degree) and Fixed and random effects under Options; Reliability Analysis has the Omega model; Descriptives has a display order (variable list, alphabetic, ascending or descending means); Logistic Regression has a selection variable with a rule (equal to, not equal to, less than and so on). The ranges tests of ONEWAY stay syntax only, as Post hoc comparisons already run them.
- LOGISTIC REGRESSION /SELECT=var relation value (EQ, NE, LT, LE, GT, GE) fits the selected cases and reports the unselected ones: the Case Processing Summary counts them, the Classification Table has a part for each group, and CASEWISE and SAVE cover them.
- ONEWAY /STATISTICS=HOMOGENEITY gives the Levene test on the mean, on the median (with the adjusted df too) and on the trimmed mean, as the manual lists. The table changed shape: a new second column says what each test is based on and each dependent has four rows, the first being the old one. Scripts or agents that read the old table by column position find the statistic one column to the right.
- ONEWAY /STATISTICS=EFFECTS adds the Fixed Effects and Random Effects rows (with the between-groups component of variance) to the Descriptives table; STATISTICS=ALL now includes them.
- ONEWAY /RANGES=LSD, DUNCAN, SNK, TUKEYB, TUKEY, MODLSD or SCHEFFE (with an optional alpha) runs the same post hoc tests as /POSTHOC.
- RELIABILITY /MODEL=OMEGA gives McDonald's omega for a scale (3 or more items), and with /SUMMARY=TOTAL the omega if each item is deleted (4 or more items).
- ONEWAY /POLYNOMIAL=degree (1 to 5) splits the between-groups sum of squares into linear, quadratic and higher trend terms in the ANOVA table, weighted and, for unequal group sizes with equally spaced groups, unweighted, each with the deviation from that degree.
- DESCRIPTIVES /SORT=key (A or D) lists the variables by mean, standard deviation, range, name or any other statistic.

## 0.20.5 (2026-11-20)

- Command line and MCP server: a file session whose output save stopped between its two folder renames takes its output back from `outputs.old` the next time it opens, instead of starting without it.
- GET DATA /TYPE=TXT: a /MAP after /VARIABLES, as text import syntax often ends, is accepted; it stopped the command with an error before.

## 0.1.0 (2026-11-10, early release)

The first version for people who want to try Statscraft and tell us what breaks. Expect rough edges; please report them on the Issues page of the GitHub repository.

### What it does

- Reads and writes .sav and .zsav files, including labels, missing values, multiple response sets, dates and old encodings.
- Macros (DEFINE with every argument kind, !LET, !IF, !DO and the string functions), INCLUDE and INSERT, syntax files in old encodings, SET, DATASET and the dictionary commands, GET DATA for text files.
- Runs the established statistics command syntax: transformations (COMPUTE, IF, RECODE, COUNT, DO IF, SELECT IF, DO REPEAT, LOOP, VECTOR, AGGREGATE, AUTORECODE, file merging, SPLIT FILE, FILTER, TEMPORARY and more) and procedures (FREQUENCIES, DESCRIPTIVES, CROSSTABS, CTABLES, MEANS, T-TEST, ONEWAY, CORRELATIONS, NONPAR CORR, EXAMINE).
- Custom tables: stacking, nesting, layers, totals and subtotals, percentages, multiple response sets, significance tests with column letters, effective base.
- Desktop window: data and variable views, syntax editor, output view, dialogs that write syntax, Excel and HTML export.
- Command line built for scripts and AI agents: sessions, running parts of a file by line range, JSON output with precise error positions, and a live link to the open window.
- OpenStatSpec: store datasets in SQLite, PostgreSQL, MySQL, MariaDB or Dolt and apply transformation plans in place.

### Known limits

- The Windows installer is not signed yet, so Windows shows an "unknown publisher" warning; see [Getting started](docs/getting-started.md).
- No charts yet. Some commands and subcommands are not supported; see [Differences](docs/differences.md) and `statscraft help`.
