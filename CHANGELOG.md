# Changelog

## Unreleased

- TWOSTEP CLUSTER (and its other name DMCLUSTER): clusters of cases from continuous and categorical variables by a pre-clustering tree and agglomerative joining, with the log-likelihood or Euclidean distance, the number of clusters fixed or chosen by BIC or AIC, noise handling, cluster distribution, centroid and frequency tables and the saved cluster number. DETECTANOMALY: peer groups from the same clustering, the anomaly index of every case with the variables that drive it, the anomaly, peer and reason lists, norms, summaries and saved indicator variables. Checked against an independent implementation of the published formulas. See [TWOSTEP CLUSTER](docs/commands/twostep-cluster.md) and [DETECTANOMALY](docs/commands/detectanomaly.md).
- Plugins: a table's `caption` gives the look of the caption under it in the exports, and with all tables on one Excel sheet `freeze_columns` keeps the first columns in view too.

## 0.16.0 (2026-11-16)

- Plugins: a setting can be a style (font, size, bold, italic, text colour, fill, alignment) edited in a Define Style window; settings can be grouped, shown in sections and in two columns when the window is wide; tables can give Excel header row heights (`header_heights`), blank rows above the table (`rows_above`), and a font and size per cell. See docs/plugins.md.
- Plugins: a plugin's answer can make cells bold or italic, give them coloured borders, style the column header cells and set a font and size for the table's exports; per table it can ask for a plain look (no default borders, header fill or bold header), stacked row labels, Excel column widths and per cell alignment. Number and text settings can have presets, a list of saved values in Edit > Plugin Settings. Web page exports and copied tables from the window now use the same table layout as the other exports.
- Plugins: `freeze_columns` keeps the first columns of an exported Excel table in view when scrolling right, and a plain table's sheet hides the Excel grid.
- `statscraft run --xlsx FILE --plugin PROGRAM`: the plugin colours, comments and lays out the custom tables of the workbook, with its settings from the active data's attributes.
- Plugins: the settings chosen in Edit > Plugin Settings are also remembered for the data file's path, so a syntax that reads the same file again (GET FILE) before it was saved keeps them.
- Window on Linux: follows the GNOME light or dark setting where the window system does not report it (as in a remote desktop session), instead of always turning dark. Edit > Settings > AI agents finds Claude Code in the usual user program folders (such as ~/.local/bin) when the window was started from the desktop menu without them on its PATH.
- Plugins: a program of your own colours the cells of custom tables and adds comments to them, through a small JSON protocol (docs/plugins.md). CTABLES tables now carry the statistics behind their cells (estimate, unweighted, weighted and effective base, standard deviation of a mean) and their total rows and columns, in the output file and in `--json`. The window runs the plugin in the background after every run (Edit > Settings > Plugins), keeps its settings as data file attributes (Edit > Plugin Settings), shows the colours and the comments on hover, saves them in the .scout file, and exports them to Excel (fills, text colours and cell notes), web pages and the clipboard. `examples/plugin-example` is a small plugin to start from.
- Window: every part of the output (command headings, titles, tables, notes, charts) is an element in the navigator with its own box to show or hide it, and Edit > Settings > Grids and output > Show in the output switches whole kinds; command headings are off by default. Copies and exports leave out what does not show unless Export hidden items is on. See [the window](docs/window.md#what-the-output-shows).
- SPECTRA, AREG and 2SLS. SPECTRA gives the periodogram and the smoothed spectral density of series (Tukey-Hamming, Tukey-Hanning, Parzen, Bartlett, Daniell or own weights), cross-spectra of pairs (cospectrum, quadrature spectrum, cross amplitude, gain, phase, squared coherency), charts as data and saved variables. AREG fits a regression with first-order autoregressive errors by Prais-Winsten, Cochrane-Orcutt or exact maximum likelihood, with iteration history, forecasts, prediction limits and APPLY. 2SLS estimates one or more structural equations by two-stage least squares, with the coefficient correlations and covariances and saved fits and residuals. Checked against a general statistics package run as a black box. See [SPECTRA](docs/commands/spectra.md), [AREG](docs/commands/areg.md) and [2SLS](docs/commands/2sls.md).

- MVA: missing value analysis. Univariate statistics with missing counts and extremes, separate-variance t tests of each variable between the cases where another is present and missing, crosstabulations by the categorical variables, the mismatch matrix, data, missing and tabulated patterns with SORT, NOSORT, DESCRIBE, ID and PERCENT, listwise and pairwise estimates, EM estimates under a normal, t or mixed normal distribution with Little's MCAR test, regression imputation with residual, normal, t or no error terms, summaries of the estimated means and standard deviations, and OUTFILE with the filled data. See [MVA](docs/commands/mva.md).
- COXREG: Cox proportional hazards regression of survival times with STATUS event values (lists and ranges, numeric or string), STRATA, CATEGORICAL covariates with every CONTRAST type (DEVIATION by default), interactions, Breslow ties, case weights and MISSING. METHOD runs ENTER, FSTEP and BSTEP with COND, LR or WALD in blocks. Tables: Case Processing Summary, Categorical Variable Codings, Omnibus Tests of Model Coefficients (-2 log likelihood, the overall score test and the changes from the previous step and block), Variables in the Equation with Exp(B) and its interval, Model if Term Removed, Variables not in the Equation, and with PRINT the correlations of the estimates, the covariate means and the baseline Survival Table of each stratum. PLOT gives survival, cumulative hazard, log-minus-log and one-minus-survival curves as chart data, at the means and at PATTERN values with BY lines; SAVE adds survival, its standard error, cumulative hazard, LML, XBETA, DFBETA and Schoenfeld residuals (PRESID). TIME PROGRAM defines time-dependent covariates from T_, and CLEAR TIME PROGRAM drops them. Checked against R's `survival` package. Not supported yet: OUTFILE. See [COXREG](docs/commands/coxreg.md) and [TIME PROGRAM](docs/commands/time-program.md).
- LOGISTIC REGRESSION: a covariate constant among the cases used but not a whole number (such as 0.1) is now left out as redundant instead of making the estimates fail. String covariates tell their categories apart by their first eight characters, as documented. A case whose dependent value is missing and whose category of a categorical covariate occurs in no other case no longer stops the command; it gets no prediction. BSTEP can now remove every term it entered, back to the model the block started from; before, the last removal stopped one step short.
- SPLIT FILE: a procedure's saved variables now keep the values of every group when the first group saves nothing, for example because it has too few cases to fit (before, they were lost); a saved string takes the width of its widest group (before, a wider value in a later group was an error); a group whose procedure failed adds no variables. See [differences](docs/differences.md).
- KM and SURVIVAL: survival analysis. KM (also K-M) gives product-limit estimates with Greenwood standard errors for each factor level within each stratum: the survival table, the mean and median with standard errors and 95% intervals, PERCENTILES, and the log rank, Breslow and Tarone-Ware tests over all levels or each pair, pooled over the strata or within each, with TREND for a linear trend; LOST cases are counted apart; SAVE adds the survival function, cumulative hazard, its standard error and the cumulative events; PLOT draws survival, log survival, cumulative hazard and one minus survival as step curves with censored times marked. SURVIVAL builds actuarial life tables over THRU/BY intervals for several survival variables and first and second order controls, with the median survival time, Wilcoxon (Gehan) comparisons (exact or approximate, overall and pairwise), GROUPWISE or LISTWISE missing values and plots of survival, log survival, hazard, density and one minus survival. ## 0.1.0 (2026-11-10, early release)

The first version for people who want to try Statscraft and tell us what breaks. Expect rough edges; please report them on the Issues page of the GitHub repository.

### What it does

- Reads and writes .sav and .zsav files, including labels, missing values, multiple response sets, dates and old encodings.
- Macros (DEFINE with every argument kind, !LET, !IF, !DO and the string functions), INCLUDE and INSERT, syntax files in old encodings, SET, DATASET and the dictionary commands, GET DATA for text files.
- Runs the established statistics command syntax: transformations (COMPUTE, IF, RECODE, COUNT, DO IF, SELECT IF, DO REPEAT, LOOP, VECTOR, AGGREGATE, AUTORECODE, file merging, SPLIT FILE, FILTER, TEMPORARY and more) and procedures (FREQUENCIES, DESCRIPTIVES, CROSSTABS, CTABLES, MEANS, T-TEST, ONEWAY, CORRELATIONS, NONPAR CORR, EXAMINE).
- Custom tables: stacking, nesting, layers, totals and subtotals, percentages, multiple response sets, significance tests with column letters, effective base.
- Desktop window: data and variable views, syntax editor, output view, dialogs that write syntax, Excel and HTML export.
- Command line built for scripts and AI agents: sessions, running parts of a file by line range, JSON output with precise error positions, and a live link to the open window.
- OpenStatSpec: store datasets in SQLite, PostgreSQL, MySQL, MariaDB or Dolt and apply transformation plans in place.

### Known limits

- The Windows installer is not signed yet, so Windows shows an "unknown publisher" warning; see [Getting started](docs/getting-started.md).
- No charts yet. Some commands and subcommands are not supported; see [Differences](docs/differences.md) and `statscraft help`.
