# Spanish glossary of the window

The terms the Spanish catalogs use, so that every part of the window says the same thing the
same way. Add a term here when a catalog uses it for the first time.

## Conventions

- Neutral international Spanish, addressing the user as *usted* ("Guarde antes su trabajo").
- Capitals as in the English source: a menu item or button starts with a capital and goes on in
  lower case ("Guardar datos como..."); a status message that is lower case in English stays
  lower case ("sintaxis guardada en ...").
- `...` after a menu item that opens a dialog, as in English.
- Not translated: syntax keywords and command names (FREQUENCIES, CTABLES, SET TVARS), names in
  parentheses after a menu item (CATREG, PROXSCAL, TSMODEL), file extensions, key names in
  shortcuts (Ctrl+C), the product name Statscraft, and names of other programs (Excel, Stata,
  PowerPoint, Word).
- The Delete key is "Supr", as Spanish keyboards label it.
